## 作品名

QuizForge（クイズフォージ）

## 一行説明

授業資料を渡すだけで、解いて採点まで終わる試験問題が手に入る Web アプリ。

---

## 概要（短） — 約 100 字

授業で配られた PDF や板書の写真をそのまま渡すと、5択・複数選択・記述・穴埋めの試験問題を自動生成する Web アプリです。記述解答は AI が部分点で採点し、間違えた問題だけを繰り返し復習できます。

---

## 概要（中） — 約 200 字

授業で配られた PDF・Word・板書の写真をそのまま渡すと、試験問題を自動生成する Web アプリです。5択・複数選択・記述・穴埋めの4形式に対応し、形式と難易度の内訳、出題範囲を指定できます。記述解答は AI が部分点で採点し、穴埋めは表記ゆれを吸収して照合します。間違えた問題だけを再出題する復習モードと AI 解説を備え、複数ユーザーでの利用、クラス単位の配布、AI 利用コストの集計まで実装しました。

---

## 概要（長） — 約 400 字

試験勉強で資料を読み返しても、思い出せるかは検証されません。市販の問題集は自分の授業資料に対応しないため、手元の資料そのものから問題が出てくる仕組みを作りました。

授業資料をそのまま渡すと試験問題が生成されます。テキスト抽出の前処理を持たない設計で、PDF・Word・板書の写真をファイルのまま扱えます。5択・複数選択・記述・穴埋めの4形式、難易度の内訳、出題範囲を指定できます。記述は AI が採点観点ごとに部分点を付け、穴埋めは表記ゆれを吸収して照合します。間違えた問題だけを再出題する復習モードと AI 解説も備えます。

技術面では、生成 AI の出力を外部入力として扱う設計を徹底しました。出題数の配分はサーバ側で確定させ、構造化出力を強制し、問題として成立しない出力は捨て、壊れた JSON は復元します。生成に約70秒かかるため非同期ジョブ化し、混雑時は再試行と代替モデルへ切り替えます。

## アピールポイント

### プロダクト

作問だけで終わらせず、**解答・採点・復習までを一貫して**扱う。
テキスト抽出の前処理を持たないため、図やスキャン PDF、板書の写真もそのまま渡せる。
複数ユーザー、クラス単位の配布、プラン別の利用上限、AI コストの集計を実装しており、
自分ひとりで使う道具ではなく運用できる状態まで作った。実際に公開して動かしている。

### テクノロジー

**生成 AI の出力を信用しない設計。** LLM に丸投げすると毎回違う失敗をするため、
責務を線引きした。文章を書く仕事だけをモデルに渡し、数と構造はコードで押さえる。

- 出題数の配分は最大剰余法でサーバ側が確定させ、モデルには確定した表だけを見せる
- Converse API の tool use で構造化出力を強制。受け付けない指定はモデル単位で学習して外す
- 問題として成立しない出力（選択肢の数、正解の個数、空欄と解答の対応）は検証して捨てる
- 実際に起きた壊れ方（値に後続キーを巻き込んで文字列化する）を解析して復元処理を書いた
- 生成に約70秒かかるため非同期ジョブ化。二重実行の防止は DB の条件付き UPDATE で行う
- 選択肢はサーバ側でシャッフルし、LLM 特有の正解位置の偏りを潰す
- 役割ごとにモデルを分けてコストを最適化。混雑時は再試行と代替モデルへの切り替えで継続する

### アイデア

**読むだけの復習を、解く復習に変える。** 資料は手元にあるのに、
それを問う手段がないという状態を解消する。
難易度を「問う内容の難しさ」だけで表現させ、文章を長くしたり形式を変えたりして
難しく見せることを禁じるなど、問題の質そのものにも踏み込んだ。

## 使用技術

| 分類 | 内容 |
|---|---|
| 言語 | TypeScript 5.8 |
| フロントエンド | React 18 / Vite 6 / PWA |
| サーバー | Node.js 20+ / Express 4 |
| データベース | PostgreSQL |
| 生成 AI | Amazon Bedrock（Converse API）／Claude Sonnet 5・GLM-5 |
| 公開 | Cloudflare Tunnel |
| その他 | Zod による入力・AI 出力の検証 |

外部の UI ライブラリは使用せず、CSS を自分で記述した。

## 規模

約 9,300 行（サーバー 4,806 行 / フロントエンド 3,636 行 / CSS 878 行）、
48 API エンドポイント、16 テーブル。

## 想定利用者

試験勉強をする学生と、演習問題を用意する教員・TA。
教員側はクラス単位でクイズを配布でき、解答履歴と復習の状態は受講者ごとに独立する。

## 動作環境

Node.js 20 以上、PostgreSQL、Amazon Bedrock を利用できる AWS アカウント。
サーバーを常駐させ、ブラウザから利用する。PWA 対応のためスマートフォンからも使える。
